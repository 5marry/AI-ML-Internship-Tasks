Task 1: Iris Dataset Visualization
Objective: Perform Exploratory Data Analysis (EDA) to understand flower feature distributions.

Tools: Python, Pandas, Seaborn, Matplotlib.

Key Insight: Petal measurements provide a much clearer distinction between species than sepal measurements.

Task 6: Heart Disease Prediction
Objective: Build a classification model to predict the presence of heart disease based on clinical health parameters.

Model: Logistic Regression.

Key Results: Achieved high accuracy in binary classification and visualized performance using a Confusion Matrix.

Task 4: General Health Query Chatbot
Objective: Develop a conversational AI assistant using Prompt Engineering to provide safe, general health information.

Model: GPT-2 (via Hugging Face Transformers).

Safety: Integrated mandatory medical disclaimers and structured system prompts to prevent hallucinations.
